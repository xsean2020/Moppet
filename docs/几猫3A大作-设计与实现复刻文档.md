### 0.3 复刻总原则（资源哲学）

1.  **确定性**：所有随机走自研 RNG（见 §2.4），种子 `?seed=`（默认 4207）。同一 seed + 同一 quality，布局/贴图/音效变体完全一致。
2.  **零资产管线**：贴图 = GPU MRT 渲染 GLSL 程序（§4）；几何 = 参数化 primitive 组合 DSL（§6.4）；音频 = 逐样本 DSP 合成（§13）；UI 标字 = Canvas2D 镂空字（§4.6/§12）。
3.  **生成即缓存**：材质 set 按名字缓存、prop 构建 key 缓存 + `clone(true)`、音效 buffer 按 `name#variant` 缓存、label 打包 atlas。
4.  **每层都有降级**：post 失败→前向渲染；模块 create 抛错→stub；pointer lock 失败→drag 模式；WebAudio 缺失→静音 stub；帧率过低→动态分辨率→自动降 quality。

### 1.5 主循环（`renderer.setAnimationLoop`）

```

__setShot 覆盖相机（若设置）

```

### 2.4 RNG（`il(seed)`）

```js
s = seed>>>0; next = () => { s = (s + 0x6D2B79F5)|0;
  let t = imul(s ^ s>>>15, 1|s);
  t = (t + imul(t ^ t>>>7, 61|t)) ^ t;
  return ((t ^ t>>>14) >>> 0) / 4294967296; }
// 扩展：range(a,b) / int(a,b) / pick(arr) / sign() / fork()（以 next()*2^32 为新种子）


```

另有 hash 变体：`F1(x,y,t)`（imul 混合 3D）、`yv(seed)`（props 内噪声表）、`ao(name)`（FNV-1a 字符串→种子，音频变体）。种子默认 `+params.seed || 4207`；enemies 用 `+params.eseed || 9001`。

## 3\. 渲染管线（render 模块）

### 3.1 Renderer 基础

```js
WebGLRenderer({canvas:#view, antialias:false, powerPreference:"high-performance",
               alpha:false, depth:true, stencil:false})
outputColorSpace = SRGBColorSpace; toneMapping 初始 ACESFilmic（HDR 路径临时 NoToneMapping）
shadowMap.enabled=true; type=PCFSoftShadowMap; autoUpdate=false（手动控帧）
autoClear=false; info.autoReset=false; clearColor 黑


```

`debug.onShaderError` 按源码标记（`SALTLINE_POST <pass>` / `SALTLINE_SKY` / 阴影 chunk）分组报错并置降级标志。

### 3.2 相机与场景（双层）

-   世界相机 `PerspectiveCamera(Pi.fov=74, aspect, 0.08, 900)`，`layers.set(0)`，rotation.order YXZ。
-   Viewmodel 相机 `PerspectiveCamera(54, aspect, 0.01, 10)`，`layers.set(1)`，矩阵从世界相机 `matrixWorld` 拷贝（`l.matrixAutoUpdate=false`，每帧 `C()` 同步），用 `gl.depthRange(0,0.05)` 压深度避免穿模。
-   天空盒：2×2×2 Box + ShaderMaterial（见 3.4），`frustumCulled=false, renderOrder=-1000, depthWrite=false`，vertex 末尾 `gl_Position = p.xyww`（推到远平面）。

### 3.3 阴影（PCSS 软阴影 patch）

-   DirectionalLight `sun`，castShadow，target=关卡 AABB 中心；shadow camera 由两组 AABB（主体 `(-41,-0.2,-33)~(37,32,31)` + 远景扩展 `(-41,-3,-64)~(72,36,34)`）投影到光空间取包围，留 1m padding，near/far ±4。
-   `mapSize = min(quality.shadow, maxTextureSize)`，`bias=-0.00012, normalBias=0.02, radius=1`。
-   `qy()` 运行时 **patch three.js `shadowmap_pars_fragment` chunk**：替换 `getShadow()` 为 PCSS（16 taps 采样 + 8 taps blocker search，low 档 10/8），实现接触硬化半影；失败（chunk 布局不识别）→ 回退 stock PCF 并 warn。
-   阴影帧控：非 ultra/非 shot 时每两帧更新一次（`(frame & 1) === 0`）；`onLevelReady` 强制重算。

### 3.4 天空与环境

**Sky shader**（`H6`，uniforms：`uTime,uEnv,uFlash,uFlashDir,uSunDir,uZen,uHor,uHorAway,uSunCol` + 256² CPU 噪声纹理 `tNoise`，噪声由 xorshift `Oy()` 生成）。成分（全部解析，无 raymarch）：

1.  晴空：`horizonColor(d)` 沿太阳方位的 3 段 pow 混色（ts^6 / ts^34 拉燃烧橙）；
2.  Mie 日冕：`pow(s,{8,64,600,6000})` 四级叠加；
3.  云层：`cuv = d.xz/(h+0.10)*vec2(0.62,0.95)`（东西向滚云）+ 风 `(-0.012,0.004)*t` + warp(fbm3) → fbm5 密度 + ridged 细节（距离淡出防锯齿）；coverage smoothstep(0.31,0.50)；**东边留燃烧缺口**（edge 由 ts^1.7 在 0.030–0.285 间插值），太阳处 `smoothstep(0.972,0.9985,mu)` 烧穿破洞；scud 薄云遮日；
4.  云光照：密度梯度自阴影 relief（densS = 向太阳偏移 0.22 再采样），slate 冷色 × relief²，暖光 = 近太阳/近缺口指数衰减，边缘 burning rim，内部片状闪电（uFlash × dot(d,flashDir)^5）；
5.  太阳盘 `smoothstep(0.999905,0.999955,mu) × 110`（uEnv=1 时不画）；
6.  地平线下海雾；PMREM 模式下 `min(col,6.0)` 压 firefly。

**环境探针**：`Vy()` = 克隆天空材质（uEnv=1）+ PMREMGenerator.fromScene → `scene.environment`，`environmentIntensity = 2`（`Jy`）。  
**室内探针**（`K()`，onLevelReady 调用）：CubeCamera 128px 置于 `interiorBoxes[0]` 中心（y = min.y + min(2.4, 0.4\*高)），uEnv=1 渲六面 → `PMREM.fromCubemap` → `render.interiorEnv`；traverse 场景把 `userData.interior===true` 的材质 `envMap` 换成室内探针，`envMapIntensity=1`（`Ky`）。相机进入室内盒子时运行时切换 `environment` 与强度（×Ky/Jy×1.35 viewFill）。

**光池**：6 个 PointLight 常驻 scene，`lightPool.flash(pos,color,intensity,dist,ttl)`（找空闲或替换最短 ttl 的非 persistent），muzzle/explosion/relay 均借光；`acquire()/release()` 供持续光（如 floodlight）。

### 3.5 HDR 目标

`WebGLRenderTarget(4,4,{type:HalfFloatType, depthTexture:DepthTexture(4,4), samples:quality.msaa, depthBuffer:true})`，depthTexture.type=UnsignedShortType，Nearest。`setQuality` 可换 msaa samples（dispose 重建）。

### 3.6 后处理链（SALTLINE\_POST，`jy`）

所有 pass 共用一个全屏大三角 + `RawShaderMaterial`(glsl3)，pass 名写在源码首行注释供错误定位。RT 池：`scene/motion/ldr`(全res) + `depthHalf/aoA/aoB/volA/volB`(半res) + `down[0..5]/up[0..4]`(bloom) + `streakA/B`(1/8 res) + `adapt[2]`(1×1 RGBA16F ping-pong) + `dirt`(512×288) + `depthCopy`(按需)。

**每帧顺序**（`P()`）：

1.  **depthcopy**（可选，供粒子软深度；depthTest+colorWrite off，仅拷 depth）；
2.  **depthhalf**：全res depth → 半res 线性 viewZ；
3.  **AO**（半res，taps = test/low:8, medium/high:12, ultra:16）： Horizon-based；法线由半res深度 4 邻域差分叉积；半径 `R = 0.9*(0.6+0.4*clamp(z/12))`；`rUv = R/(2 z tanHalf)` clamp \[3texel, 0.14\]；IGN（interleaved gradient noise）旋转；权重 `f³·max((vn-0.015-0.004z)/(vv+0.004),0)`；归一化 `1 - intensity*sum*5/(R⁶·taps)`；z>70→140 线性回 1；
4.  **blur-ao**：7-tap 双边（深度容差 `0.04z`），H+V 两趟；
5.  **Volumetric**（半res，VOL\_STEPS = preset）：raymarch 视线；步长分布 `t = maxD·f·(0.35+0.65f)`（近处加密）+ IGN 抖动；相位 = 双叶 HG `hg(mu,0.78)*0.55 + hg(mu,0.25)*0.45`（前向金光 + 侧向可见光柱）；遮蔽 = 采样太阳 shadow map（RGBA pack 解码 + step(z-0.0006)）；高度衰减 `shape(h)=0.3+0.7·exp(-h/5.5)`；室内 box 内 `uBoxDust=6` 消光增强、天空环境 ×0.22；近眼权重 `mix(2.3,0.55,smoothstep(4,85,t))`（近处光柱浓）；远几何（>maxDist=170）解析续接 horizon 色 haze（`volFarHaze=0.42`）；
6.  **blur-vol**：同 AO 但容差 `0.30z`；
7.  **composite**（写回 scene RT）：4-tap 双边上采样（权重 × `1/(0.015+|z差|/z)`）；AO 只压环境光（亮度 >0.16..0.85 处淡出 80%），并带微冷色调 `(0,0.03,0.07)`；`col = col*vol.a + vol.rgb`；
8.  **motion blur**（可选）：上一帧 viewProj 重投影速度场，9-tap + 抖动，快门 `min(0.5, 1/190/dt)`，速度上限 0.018uv，仅背景层（sky 像素跳过）；
9.  **bloom**：6 级 down（首级 13-tap + Karis 部分平均灭 firefly，上限 400）→ 逐级 up（tLow×4 + 十字邻域，`uMix=0.62`）；
10.  **streak**：1/8 res 横向 7-tap 高斯，首趟阈值 `2.2/exposure`，第二趟无阈值（宽 5×）；用于 anamorphic 拉丝；
11.  **adapt**（1×1）：7×5 中心加权 log 平均亮度 + 12 点螺旋（r≤0.011）深度采样测太阳可见度；`rate = 1-exp(-dt/1.5)`（前 2 帧或 fast=1）、visRate 0.12s；NaN/首帧保护；
12.  **grade**（合成一切到 LDR RT）：
     -   曝光 `slExposure() = uExposure * mix(1, clamp((key/lum)^0.85, 0.6, 2.0), uAuto)`，key=0.12，adapt 纹理传入；游戏级曝光 = `0.6 * exposure * (1-fade)`（fade 时压暗）；
     -   bloom `0.065`、lens dirt `0.1`（procedural：70 个随机 disc + fbm 污渍 + 纵向擦痕，边缘权重）、streak `0.03`（阈值 2.2）、太阳耀斑 `0.16`（ghosts 沿日-心轴 + 对侧 halo，`uSunOn` 需太阳在视野内且不在屏幕外 0.3 缓冲）；
     -   色差 `0.0013`（受伤时增大）；AgX(Filament fit) 与 ACES(Hill fit) 按 `agxMix=0.25` 混合；split-tone（阴影偏 teal，高光暖）+ S 曲线 + 提亮黑位 + `LOOK_POWER=1.18 / LOOK_SAT=1.22` 的 punchy AgX；
     -   vignette `0.3`（低血量 + ADS 收紧）、damage 红边脉冲、flash、fade、gameplay saturation；

### 3.7 动态分辨率与自动降档

-   `dynres` 默认开（shot/show 关闭）；3.5s settle 后，以 45 帧或 900ms 为窗口取平均帧时：
    -   `>21.5ms` → scale −0.1（>30ms −0.2），下限 0.6，upDelay 翻倍（≤60s）；
    -   `<17.4ms` → +0.1（需等待 upWait）；

-   像素预算上限 `{low:1e6, medium:1.5e6, high:2.3e6, ultra:3.7e6}`，超出再乘 `sqrt(budget/actual)`；DPR cap 2。
-   后处理链任何 pass 运行时抛错 → `advanced=false` 整体回退前向渲染（toneMapping=ACES、直渲 + 简单 grade）。

## 4\. 材质系统（mats 模块）— 程序化 PBR 贴图工厂

### 4.1 生成架构（核心资源管线）

每个 **texture set** 用一次 **MRT 渲染**（WebGLRenderTarget `count:3`，HalfFloat）在 `<size>×<size>` 上同时输出：

| target | 内容 | 编码 |
| --- | --- | --- |
| o0 | albedo.rgb + alpha | `sqrt(albedo)`（提高低值精度） |
| o1 | ORM | R=AO, G=Roughness(clamp 0.03..1), B=Metalness |
| o2 | height | R=height 整数部分/255，G=小数部分（16bit 手工打包） |

随后两个补丁 pass：

-   `copy`：albedo 目标 = `pow(rgb,2)`（逆 sqrt）→ 8bit RT（sRGB）；
-   `normal`：对 height 目标做 **Sobel 梯度→法线**，`uK = (bump*0.001*size/tileX, bump*0.001*size/tileY)` 控制strength → 8bit RT（linear）。

RT 参数：`wrapS/T=Repeat, minFilter=LinearMipmapLinear, magFilter=Nearest(生成期)/Linear, anisotropy=min(8,max), mipmap on`；`texture.repeat = (1/tileX, 1/tileY)`（世界米制平铺）。

-   分辨率 `res = round(tex * set.size)`（`tex`\=quality.tex），clamp ≥32；`hero:true` 且 tex≥2048 → 2048（仅 asphalt）。
-   同分辨率共享一个 MRT；同 gen 函数共享 program。
-   **GC**：生成用临时 RT 4 秒后无人新增即 dispose（`update()` 里检查）。
-   stats：`{sets, textureMB(bytes=size²*4*1.34*3 目标), genMs, decalMB}`，showcase 会打印。

## 5\. 物理与导航（physics 模块）

### 5.1 AABB 世界

`addBox(min,max,{surface,tag,noNav,bulletOnly,playerOnly})` → boxes 数组（surface ∈ concrete/metal/wood/rubber/water/glass/dirt）。`build()` 光栅化 nav grid（脏标记触发）。

-   **raycast(o, d, maxDist=500)**：对每个 box 做 slab 测试（记录命中轴与内外向）；地面平面：`d.y<0` 时与 y=0（限 x≤quayX=30）求交，否则与 seaY=-1.6；返回 `{dist, point, normal, surface, box}`（surface="water" 命中海面）。
-   **lineOfSight(a,b)**：`!raycast(a, dir, dist-0.05)`。
-   **groundHeight(x,z,maxY=50)**：遍历 boxes 取 `max.y ≤ maxY` 的最大值（x≤quayX 起点 groundY=0，否则 -50）。
-   **moveCapsule(pos, vel, dt, r=0.32, h=1.8, stepUp=true)**：
    -   水平：按 `ceil(|v|/(r*0.6))` 子步；对每个 box 求圆心到 box 的 2D 最近点，`dist<r` 则沿法线推出（深处则按四边最近面弹出），速度去法向分量；迭代至多 3 次；
    -   台阶：box 顶 `≤ pos.y + stepH(0.42)` 的才参与水平阻挡（stepUp 模式）；
    -   垂直：脚底支撑 = 足印 (r\*0.7) 覆盖 boxes 的最大 `max.y ≤ y+stepH`（或地面平面），`min.y ≥ y+h` 为天花板；落地贴地、`onGround/hitWall/hitCeil/surface`。

-   几何库：`$e` 盒 / `Ge` 斜角盒 / `ot` 圆柱 / `us` 车削 profile / `xr` 2D 轮廓拉伸 / `zr` 两点梁 / `Fn` 样条管；
-   **实例缓存**：`wf(key, build)`（barrel/pallet/jerry\_can/cone 等 4 变体），命中直接 `clone(true)`（几何共享）；
-   定制大件：`oR forklift / rR generator / aR dumpster / lR toolbox_cart / QA tarp_cargo(防水布样条) / tR sandbags / nR cardboard` 各自程序化建模；
-   未知 name → 直接按 Gi 尺寸生成盒 + 默认碰撞。

### 6.5 Label Atlas（`rb`）

遍历 staticRoot 找材质 name==="label" 的非动态 mesh：按 0.5 缩放打包进 ≤2048² canvas（skyline 排布 + 4px padding + clearRect 锯齿修复），重映射每个 mesh 的 UV 到 atlas 格子，统一换 `label_atlas` 材质；运行时 `update` 检测 `map.version` 变化重打包（前 8 秒内）。

### 6.7 地面（ground `O1`）

**对象**：一块 190×320 平面（rotateX -90°，translate x−65）+ skirt + 雨纹 splash 系统；全部通过 `onBeforeCompile` 注入 MeshStandardMaterial（name "apron\_wet"，cache key "saltline-apron-3"）。

**输入贴图**（全部 CPU 生成）：

-   `mask` 1024² 独一无二（世界 80×80m 映射，`Li={x0:-44,z0:-40,size:80}`）：R=积水高度场 `SR(x,z)`（基 fbm − 15 个椭圆洼地 `Sb` × `Tb` − 两条排水沟带 + quay 边坡 0.25 bump）、G=湿度 fbm、B=油渍/磨光、A=磨损；
-   `detail / detailN` 512² 平铺（detail：R 细颗粒、G 中等斑驳、B ridged、A 宏观；N：两层 fbm 梯度→RG/BA 双 normal）；
-   `marks` 2048² **世界坐标标线图集**（`fa={x0:-40,z0:-30,w:70,h:60}`，composite "lighter"）：R=黄漆（车道线/区域框/箭头）、G=白漆（斑马纹/编号）、B=轮胎橡胶黑；文字用 `900 100px PingFang SC` 绘制后逐字 `fillRect` 打孔做镂空磨损；含 dashed 线、45° hatch、字符印章。

**AR 片段注入**（逐层算法，全部世界坐标驱动）：

1.  6m 伸缩缝 + 焦油封（tarW 由 d1.g 噪声）；
2.  裂纹（d1.b 阈值 × 区域）+ 20% 焦油补缝；
3.  底色：`x≈16` 用 smoothstep 混 asphalt(0.125 灰)/concrete(0.22 暖)，骨料亮斑、抛光带压暗、油渍 −62%；
4.  标线：mip 感知（kpx = fwidth×res）<1px 时换 bicubic 采样；`chipN` 世界坐标 3 频 value-noise（按相机距离启用 17/57/181Hz）→ 漆面剥落 `keep`；黄/白漆 + 轮胎黑；
5.  **水系统**：`depth = 0.5 - mask.r + 噪声(40/15/5cm) + 缝槽/裂纹扰动`；`puddle=smoothstep(0,0.035,depth)`（5cm 镜面坡）、`deep`（≥22cm 浑浊变暗）、`soak`（10–30cm 浸润带）、`damp`（1m 湿晕）；albedo/roughness 全程平滑 ramp（0.74 干 → 0.36..0.56 湿 → 0.1..0.2 浸透 → 0.055 镜面）；
6.  normal = detailN 双层 + `gRipple` 雨圈（两轴旋转叠加、`uRain` 强度、仅近处 rf<34m）+ 风驱微波（两张 detailN 慢速平移）；
7.  **RR 平面反射**：`uReflMatrix` = 反射相机 viewProj × 轴向矫正矩阵（prepass `zb` 在 y=0.01 镜面渲染 layer0，分辨率 = 主 res × quality.planar，带 oblique near-plane 裁剪）；LOD：`lodP = rough*9.5-0.45+0.9`（积水镜面仅微柔）vs `lodD = 3+rough*6.5-3.4·graz`（湿地面纵向拉伸 sheen）；3-tap 纵向偏移采样；上限 48 防过曝。

**雨**：`Nb` = 雨幕 mesh + instanced splash（落点涟漪，`uRain` 缩放）；室内（interiorBoxes）自动衰减（weapon.setWetness 同源判定）。雷暴：update 内 30–60s 随机 `events.emit("thunder",{intensity})` → render 闪光曲线（0.9s 双正弦衰减 ×0.35）+ sky uFlash + audio thunder。

-   **touch**：任意 touchstart 激活；左侧 45% 屏 = 浮动摇杆（半径 58px，dead 0.16），右侧滑动转向（0.0052 rad/px）；按钮：开火（可拖跟枪）/瞄准(toggle)/换弹/跳跃/交互/暂停；`is-touch` 类钩子；
-   **gamepad**（standard mapping）：L 摇杆移动、R 摇杆视角、RT fire、LT ads、A jump、B crouch、X reload、Y interact、L3 sprint、RB/LB melee、Start pause（radial dead 0.16）。

契约：`move{x,y}, look{dx,dy}, fire, ads, sprint, crouch, locked, touch, gamepad, sensitivity, invertY, mode, down(k), pressed(k), update, endFrame, requestLock, exitLock, setGameplay, setPrompt, onModeChange, describeMode`；`g_={pause:1}` 暂停键非 gameplay 也响应；UI 聚焦时吞键（INPUT/SELECT/TEXTAREA、BUTTON 上的 Space/Enter）。

## 13\. 音频系统（audio 模块，全程序化合成）

### 13.1 主图（WebAudio）

```
bus world ─┬─ N(gain0.9) ─ q(gain1) ─┬─ convolver(ir_outdoor) ─ G(0.75) ─┐
bus near  ─┼─ Q(0.32) ─ q ───────────┴─ convolver(ir_shed) ──── j(0.95) ─┤
           │                                                             ├→ S lowpass20k → mute
bus amb   ─┴───────────────────────────────────────────────────────────→ │   (死亡低通 2e4·0.03^d)
bus dry  ────────────────────────────────────────────────────────────→ A(g1)
bus music(0.62) ─ K(0.2..0.32 室内) ─ ir_shed ───────────────────────→ │
A → compressor(th-10dB knee6 ratio6 atk0.002 rel0.14) → M(0.45)
  → waveshaper(soft-knee tanh: ≤0.6 直线，>0.6 tanh 混合, 2x oversample) → w(volume) → destination

```

Panner：世界音 `panningModel = HRTF`（`?noaudio` 无关），per-sound `ref/roll` 距离衰减；listener 跟相机。

### 13.2 合成机制

-   `Go` 定义 **57 个音**，字段 `{gen, n 变体, sr, peak, bus, max 同时音, pri, ref, roll, boot(启动即合成), loop, ir, music}`；采样率 `ki=44100 / Xn=32000 / pl=22050`，音乐 32k。
-   生成器 = 生成器函数 `(sr, rng, variant) → {ch:[L,R], sr}`（DSP 工具：`St` 缓冲、`Qn` 白噪、`at` 包络噪声、`dn` 模态叠加（频率/衰减/幅度组）、`Av` RBJ biquad、`Ns` MIDI→Hz）；变体种子 = FNV1a(name)+variant×7919。
-   **预算式合成**：boot 优先合 `boot:1` 清单；其余 `step()` 每 6ms 切片、12ms 定时器排队；`when(name,variant,cb)` 请求可插队。`ready` Promise 全队列清空后 resolve。
-   **关键音色示例**（rifle\_shot，4 变体）：crack（2.6kHz HP 瞬态 12ms）+ 中频体（300-2500Hz 22ms）+ 低频 thump（160Hz 模态 110ms）+ 弹匣机械（760Hz BP）+ 高频尾巴（4.8kHz 160ms）；变体 detune `[1,0.955,1.045,0.985]`；2.6ms/27ms 处叠加双反射 slap。
-   **卷积 IR**：`ir_outdoor` / `ir_shed` 均程序化生成（噪声衰减脉冲响应）；室内外按 `setInterior()` 交叉淡化（q/T 增益）。

### 13.3 循环与自适应音乐

-   循环层：`rain / rain_interior / wind(pitch 0.9-1.15 慢漂移) / sea(定位 x=33 码头)`；gull\_rotor / hound\_servo / relay\_hum 挂实体（`loop(name,{pos,gain})` 返回 `setPos/setGain/setPitch/stop`）。
-   音乐 5 层（drone/ost/perc/brass/motif，`Fr={bpm:100, bar:2.4s, loopBars:8, sr:32k}`），音量由强度曲线 `we(L)` 分层插值；`L` 由 `setIntensity`（game：巡逻 0.15 / 警觉 0.6 / 战斗 1）平滑驱动；标题 0.7。
-   状态副作用：死亡 → 低通闷化 + rain/wind 压低；暂停 → `setPaused(true)` 停新音保持 loop；UI click/hover。
-   **selfTest()**：OfflineAudioContext 渲 10s 脚本化场景（spawn/alert/开火/换弹/爆炸/击杀/目标完成），输出 `{renderMs, peak, over, nan, rmsDb[], inst}`——可作 CI 音频回归。

## 14\. 性能与内存策略

1.  **Draw call 控制**：静态合并（§6.3）+ label atlas + 材质缓存共享 + viewmodel 独立层 + 粒子单 draw 实例化 + 光池仅 6 盏。
2.  **半分辨率延迟效果**：AO/体积光/深度均 1/2 res + 双边上采样；bloom 6 级；planar 反射按 quality.planar 比例。
3.  **帧预算**：阴影隔帧（ultra 除外）；贴图生成在 boot 一次性完成（`[boot] mats <ms>` 可观测）；音频合成 6ms 切片。
4.  **内存**：RT 池复用（bloom down/up 环）、生成用 MRT 4s GC、贴图总账（mats.stats().textureMB）、typed array 环形池（粒子/tracer/shell）。
5.  **移动端**：low 档（scale 0.7 / 无 AO/planar/MB / rain 0.5 / shadow 2048 / msaa 0）+ 触屏 UI + safe-area 适配 + HRTF→equalpower 可降。
6.  **自适应**：动态分辨率 21.5/17.4ms 阈值 + quality 自动降档（§3.7）；shader 编译失败逐 pass 降级（§1.4）。
